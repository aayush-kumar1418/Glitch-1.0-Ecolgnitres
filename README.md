##  Features

-  Environmental awareness and ecological information
-  Emergency guidelines and safety protocols
-  Actionable guidelines for environmental crises
-  About section with mission and vision
-  Clean, responsive UI built with pure HTML & CSS

##  Getting Started

No installation needed — open directly in browser:

```bash
git clone https://github.com/aayush-kumar1418/Glitch-1.0-Ecolgnitres.git
cd Glitch-1.0-Ecolgnitres
# Open glitch.html in your browser
```

Or visit the **[Live Demo](https://glitch-1-0-ecolgnitres.vercel.app)** directly.

---

##  About This Project

Built for **Glitch 1.0 Hackathon** — a competition focused on building solutions for real-world environmental challenges. Ecolgnitres was created to spread ecological awareness and provide emergency preparedness information in an accessible, easy-to-use format.
